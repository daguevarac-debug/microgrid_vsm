# Validación de la regulación del enlace DC

Este documento es generado de forma reproducible por:

`src/validation/validate_dc_link_bess_soh_support.py`

La ejecución registra:

- descarga efectiva del BESS durante el déficit posterior al escalón severo del 40 %;
- cumplimiento de límites de corriente, potencia, SoC y SoH;
- resultados para SoH 1.00, SoH 0.70 y SoH nominal;
- comparación del caso anterior sin soporte y el caso corregido con PI+BESS;
- criterios, limitaciones y rutas de todos los archivos generados.

Antes de cerrar la tarea, ejecute el script para reemplazar este contenido base por la tabla y los resultados numéricos locales.
